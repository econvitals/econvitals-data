# econvitals-data

The data plane for econvitals.org: chart data (JSON) and chart images (PNG), read by the site's
pages directly over raw.githubusercontent.com URLs (commit-pinned where freshness matters).
Everything here is already publicly served on econvitals.org; nothing sensitive belongs in this
repo — briefings PDFs, maclow research summaries, and all page code live in the (private)
econvitals/site repo.

Layout mirrors the site's paths one-to-one: `data/`, `img/`, `lab/<slug>/`, `tools/<slug>/`.

Writers: the chartbook release desk and slow lane on the fleet host, plus the relocated
lab/tools refresh workflows. Every writer must push with the fetch + merge --ff-only retry
pattern. History is compacted monthly (orphan-branch swap, Saturday chore).

Removals: the chartbook publish deletes the `data/` and `img/` files of any chart that is still
awaiting review, retired or deleted (`render/deliver_dashboard_pngs.py` `withdrawn_slugs()`, since
2026-10-08), unless a page still names it; other writers' files are never touched. It also never
publishes, and withdraws, a chart that is never for the web — the Ec10 lecture exhibits, and any
chart marked `web: false` because its history belongs to another publisher (the ISM indexes and
NAR's housing affordability index came off on 2026-10-27, Jason: proprietary history; ISM,
Conference Board, S&P Global, Chicago PMI and NAR history never goes here without the publisher's
written permission). **Old copies of those two files remain in this repo's public git history**; the
take-down did not rewrite it. Its daily
`render/check_data_repo_strays.py` names any file nothing on the site reads.

Spec: `chartbook/REBUILD.md` (Stage B, the data plane). Created 2026-08-10.

**The composite GDP tracker's two files (2026-10-18).** `data/gdp-nowcast-history.json` is appended by the chartbook publish (`render/publish_data.py`) after every dashboard build: one snapshot per day per quarter of Econvitals' composite current-quarter GDP tracker and its legs, plus a scored row per quarter once BEA's advance estimate is out. `data/gdp-nowcast-backtest.json` is the archive back-test from the Atlanta and New York Feds' own records, regenerated by `render/dashboard/gdp_composite.py --backtest`. Both are read by the GDP page's track-record table (`assets/subpage.js`). Because this repo's history is compacted monthly, the history FILE is the record — never rely on the commit log.
